# Personal Website

Rocky Yu's one-page portfolio, hosted on GitHub Pages at https://rockyyu000-commits-goo.github.io.

## Files

- `index.html`: the whole site, styles included.
- `.nojekyll`: tells GitHub Pages to serve the files as they are.

## Editing

Replace the placeholder text in `index.html`. To add an entry, copy an `<li>` block inside a section.
Colors are the variables at the top of the `<style>` block (light and dark).

## Deploy

1. Create a public GitHub repo named `<your-username>.github.io`.
2. Push this folder to its `main` branch.
3. The site goes live at `https://<your-username>.github.io` within a minute or two.
   If it doesn't, check Settings → Pages: Source "Deploy from a branch", branch `main`, folder `/ (root)`.

## Local preview

Open `index.html` in a browser.
